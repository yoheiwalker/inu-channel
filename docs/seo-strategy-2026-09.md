# 犬ちゃんねる SEO実行計画（2026年9月）

## 結論

犬ちゃんねるは、競合の「広い動物ランキング」と「少数の犬アカウント紹介記事」の間を狙う。勝ち筋は、犬だけに特化し、犬種・発信者・SNSを横断しながら、動画内容を実際に確認した独自要約まで提供すること。

## 狙う検索テーマ

### 最優先

- 犬 YouTube チャンネル まとめ
- 犬 YouTuber 人気 / ランキング
- 犬 動画 人気 / 再生回数ランキング
- 柴犬 YouTube / チワワ YouTuber / トイプードル Instagram など「犬種 × SNS」
- 犬 インスタ 人気 / 犬 TikTok 人気

### 次に広げるテーマ

- 子犬 しつけ YouTube
- 犬 歯磨き 動画
- 犬 トリミング 動画
- 犬 フード 選び方 YouTube
- 犬種名 × 子犬 / 成犬 / シニア / 多頭飼い

検索語を不自然に繰り返さず、各ページのタイトル、見出し、説明、内部リンクに自然に配置する。

## 今回実装した内部対策

- 犬種別13ページと発信者別6ページを新設
- ページごとに固有のタイトル、説明、canonical、OG情報を設定
- 動画詳細に `VideoObject` とパンくず構造化データを追加
- 犬種・カテゴリ一覧に `CollectionPage` と `ItemList` を追加
- トップに `WebSite` と運営組織情報を追加
- sitemapへ犬種別・発信者別・運営情報・編集方針ページを追加
- robotsで公開ページを許可し、APIだけをクロール対象外に設定
- トップ・動画詳細・一覧ページ間の内部リンクを追加
- 「このサイトについて」「掲載・編集方針」を新設し、選定・数値・医療情報・広告・訂正方針を明文化
- Search Console確認コードを環境変数から設定できる入口を追加

## 外部対策（送信前プラン）

### 1. 掲載クリエイターから自然な紹介を得る

掲載済みの発信者へ、リンクを条件にせず「紹介ページを作成したので、情報の誤りがあれば教えてください」と連絡する。気に入った方がプロフィールやブログで自発的に紹介しやすい、各犬種・カテゴリ・動画の直リンクを案内する。

### 2. 犬関連メディアへデータ企画を提案

単なる相互リンク依頼ではなく、次のような独自データを提供する。

- 犬種別に見たYouTube・Instagram・TikTokの発信者数
- 今月伸びた犬動画ランキング
- 子犬・成犬・シニアでよく見られる動画テーマ
- 獣医師・トレーナー動画の人気テーマ

### 3. SNSで更新情報を継続発信

- 週1回「今週の犬動画TOP5」
- 週1回「犬種別の推し3組」
- 月1回「犬クリエイター動向」
- 各投稿から該当する犬種別ページへ誘導

### 4. 避けること

- 有料で順位操作用リンクを買う
- 自動ツールで大量の被リンクを作る
- リンク交換だけを目的とした相互リンク集
- 掲載の条件としてリンクを強制する

## 効果測定

Search Consoleを接続し、毎月同じ条件で確認する。

- 自然検索クリック数・表示回数
- 検索語別の順位とCTR
- 犬種別ページの流入数
- インデックス済みページ数と除外理由
- 「公式プロフィールへ移動」「動画を見る」「掲載希望」のクリック数

最初の評価は公開後28日、次は56日。順位だけでなく、公式動画へのクリックと掲載希望の増加を成果に含める。
